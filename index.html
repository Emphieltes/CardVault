Cloud setup (free, one-time)

CardVault uses Google Firebase (free tier) so your list follows your login. Takes about 5 minutes. You only do this once, then paste the same config on each device (or keep it in this HTML file).

  1. Go to console.firebase.google.com → Create project
  2. Add an app → Web → copy the firebaseConfig object
  3. Build → Authentication → Sign-in method → enable Email/Password
  4. Build → Firestore Database → Create database (start in production mode)
  5. Firestore → Rules → paste the rules shown below → Publish
  6. Paste your config JSON below → Save
